# DGQ63136.cn 前端

斗鱼 63136 弹幕库网站前端。

## 项目说明

本仓库只保存公开网站前端代码和必要的公开静态资源。

主要包含：

- 网站首页
- 弹幕库浏览页面
- 图片展示页面
- 插件安装入口页面

## 本地运行

```powershell
npm install
npm run dev
```

## 构建

```powershell
npm run build
```

`npm run build` 会在 Vite 构建后执行 `tools/verify-build-assets.mjs`。发布前必须确认：

- `dist/assets` 里不能出现 `.pnpm.*` 这类点开头文件。
- 入口 JS 不能引用 `./.xxx` 点开头 chunk。
- 构建产物里不能带本机磁盘路径。

原因：公开域名/CDN/GitHub Pages 链路可能不返回点开头静态资源，页面会停在加载中。

## 插件更新发布规则

本仓库的插件安装页只负责展示和分发公开 `.user.js` 文件。更新插件时按下面规则处理：

1. 从油猴脚本源码仓库取最新发布文件 `releases/Vx.y.z/dgq63136.user.js`。
2. 只复制到本仓库 `public/dgq63136.user.js`，不要额外上传 zip 或重复安装包。
3. 同步更新安装页显示的当前版本号、更新时间、更新记录和安装链接缓存参数。
4. 推送后先确认 GitHub raw 文件已经是新版本，再检查 `https://dgq63136.cn/dgq63136.user.js`。
5. 如果 GitHub 已新、线上域名仍旧，说明是 Pages 或 CDN 缓存未刷新，优先清缓存，不要重新覆盖网站源码。

更新安装页时不要重建或覆盖无关页面；只改安装页版本信息和 `public/dgq63136.user.js`。
