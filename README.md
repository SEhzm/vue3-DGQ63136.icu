# DGQ63136.cn 前端

斗鱼 63136 弹幕库网站前端。

## 项目说明

本仓库只保存公开网站前端代码和必要的公开静态资源。

主要包含：

- 网站首页
- 弹幕库浏览页面
- 图片展示页面
- 插件安装入口页面

## 本地运行

```powershell
npm install
npm run dev
```

## 构建

```powershell
npm run build
```
